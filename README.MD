# Программный комплекс анализа Wi‑Fi Probe Request с геолокацией точек доступа

## Общая информация

Данный программный комплекс разработан в рамках выпускной квалификационной работы и предназначен для анализа Probe Request пакетов беспроводных сетей стандарта IEEE 802.11 с последующей геолокацией обнаруженных SSID посредством API сервиса WiGLE и визуализацией результатов на интерактивной карте.

Программа реализует полный цикл обработки данных: от захвата трафика до построения карты расположения точек доступа.


## Цель разработки

Целью разработки является создание программного инструмента для автоматизированного анализа Wi‑Fi активности и пространственной визуализации данных о точках доступа на основе открытых источников.


## Основные функции программы

- Перевод сетевого интерфейса в режим мониторинга  
- Захват Wi‑Fi трафика с использованием airodump-ng  
- Извлечение уникальных SSID из Probe Request пакетов  
- Фильтрация некорректных идентификаторов  
- Выполнение запросов к WiGLE API с поддержкой пагинации  
- Сохранение полученных данных в формате JSONL  
- Построение интерактивной HTML‑карты с использованием библиотеки Folium  
- Интерактивное меню управления процессом анализа  


## Требования к программной среде

### Операционная система
Linux (Kali Linux, Ubuntu или совместимые дистрибутивы)

Программа использует:
- ip
- iw
- airodump-ng
- режим мониторинга сетевого интерфейса

Запуск под Windows возможен только через WSL с установленными инструментами aircrack-ng.

### Требуемое программное обеспечение

- Python 3.9 или выше  
- aircrack-ng  
- pip  


## Используемые библиотеки Python

Зависимости указаны в файле requirements.txt.

Установка:
pip install -r requirements.txt

## Запуск программы

Перед запуском необходимо:

1. Подключить Wi‑Fi адаптер с поддержкой режима мониторинга.
2. Запускать программу с правами суперпользователя.

Команда запуска:
python main.py
